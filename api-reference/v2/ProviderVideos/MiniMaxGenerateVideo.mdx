## Endpoint

```http
POST https://api.jogg.ai/v2/minimax/videos/generations
```

Submit a paid MiniMax request using either `prompt` or supported `content` media.
The active model configuration determines valid modes and pricing.

See [Provider Video Generation](/api-reference/v2/API Documentation/ProviderVideos).
