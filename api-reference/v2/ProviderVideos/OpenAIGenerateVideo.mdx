## Endpoint

```http
POST https://api.jogg.ai/v2/openai/videos/generations
```

Submit a paid `sora-2` request using `prompt`, `input_reference`, `seconds`, and
`size`. The response is a JoggAI asynchronous task.

See [Provider Video Generation](/api-reference/v2/API Documentation/ProviderVideos).
