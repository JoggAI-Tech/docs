## Endpoint

```http
POST https://api.jogg.ai/v2/google/videos/generations
```

Submit a paid Veo request using one `instances` item and supported `parameters`.
When `lastFrame` is provided, the same instance must also include `image` as the first frame.
Input images must come from the JoggAI upload flow.

See [Provider Video Generation](/api-reference/v2/API Documentation/ProviderVideos).
