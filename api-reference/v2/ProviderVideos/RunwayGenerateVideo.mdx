## Endpoint

```http
POST https://api.jogg.ai/v2/runway/videos/generations
```

Submit a paid Runway request using `promptText`, `promptImage`, `ratio`, and
`duration`. `promptImage` is required because the current Jogg integration uses
Runway image-to-video. Reference media must be a Jogg OSS asset URL.

See [Provider Video Generation](/api-reference/v2/API Documentation/ProviderVideos).
