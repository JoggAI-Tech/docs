## Endpoint

```http
GET https://api.jogg.ai/v2/videos/tasks/{task_id}
```

Retrieve a provider video task in the current Space. Cross-Space and unknown
task IDs return the same not-found response. This read-only endpoint does not
create or charge for generation work.
