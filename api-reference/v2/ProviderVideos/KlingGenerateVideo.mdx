## Endpoint

```http
POST https://api.jogg.ai/v2/kling/videos/generations
```

Submit a paid Kling request using `prompt`, `contents`, `settings`, and `options`.
Only combinations supported and priced by the active JoggAI model configuration are accepted.

See [Provider Video Generation](/api-reference/v2/API Documentation/ProviderVideos).
