## API Credit Consumption

JoggAI API uses a credit-based pricing model. Credits are consumed based on the type of operation and resource usage.

---

## Credit Pricing Table

<Tabs>
<Tab title="New subscription">

| Service | Consumption | Details | Endpoint |
|---------|-------------|---------|----------|
| **Avatar Video** | 250 credits per 15 seconds | Duration rounded up to the next 15 seconds; minimum 30 seconds (500 credits) | `POST /v2/create_video_from_avatar` |
| **Video Translation** | 125 credits per 15 seconds | Per target language; duration rounded up to the next 15 seconds; minimum 30 seconds (250 credits per language) | `POST /v2/video_translate/` |
| **Lip Sync Video** | 125 credits per 15 seconds | Duration rounded up to the next 15 seconds; minimum 30 seconds (250 credits) | `POST /v2/create_lip_sync_video` |
| **Preview Video** | 125 credits per 15 seconds | Duration rounded up to the next 15 seconds; minimum 30 seconds (250 credits) | `POST /v2/create_video_from_product/preview_list` |
| **AI Scripts** | 40 credits per call | Per API request | `POST /v2/ai_scripts` |
| **Avatar Photo Generation** | 10 credits per image | Single image generation | `POST /v2/photo_avatar/photo/generate` |
| **Avatar Photo Generation(Batch)** | 40 credits per call | Generates 4 images | `POST /v2/photo_avatar/photo/generate` |
| **Photo Avatar Generation** | 600 credits | Per motion generation | `POST /v2/photo_avatar/add_motion` |

</Tab>

## Check Your Balance

You can check your remaining credits via:

- **Dashboard:** Visit [app.jogg.ai](https://app.jogg.ai)
- **API:** Use the [Get User Info](/api-reference/v2/User/GetUserInfo) endpoint
- **API:** Use the [Get Remaining Quota](/api-reference/v2/User/GetRemainingQuota) endpoint

<Note>
Credits are deducted immediately when a request is processed, not when it completes.
</Note>
