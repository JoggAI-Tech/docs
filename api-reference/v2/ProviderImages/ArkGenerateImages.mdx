## Endpoint

```http
POST https://api.jogg.ai/v2/ark/images/generations
```

Submit a supported Seedream image request using Ark field names. This paid
operation returns a JoggAI asynchronous task.

See [Provider Image Generation](/api-reference/v2/API Documentation/ProviderImages).
