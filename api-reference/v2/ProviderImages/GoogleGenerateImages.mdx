title: "Generate Images with Google"

Submit a supported Gemini image request. This paid operation returns a JoggAI
`task_id`; poll the unified image task endpoint for results.

See [Provider Image Generation](/api-reference/v2/API Documentation/ProviderImages)
for upload, billing, strict-field, and retry guidance.
