## Endpoint

```http
GET https://api.jogg.ai/v2/images/tasks/{task_id}
```

Retrieve a provider image task in the current Space. Cross-Space and unknown
task IDs return the same not-found response. This read-only endpoint never
submits or charges for new generation work.
